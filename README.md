## 🚀 Quick Start

### Prerequisites
- Node.js v18+
- npm or yarn
- OpenAI API key (optional — works in demo mode without it)

### Setupcd studypath-ai/backend
npm install
npm run dev   # or npm start

**1. Clone the repo**
git clone https://github.com/YOUR_USERNAME/studypath-ai.git
cd studypath-ai

**2. Start the backend**
cd backend
cp .env.example .env
# Add your OPENAI_API_KEY in .env (optional)
npm install
npm run dev

**3. Start the frontend**
cd ../frontend
npm install
npm run dev

**4. Open in browser**
http://localhost:5173

## 🎯 Features

| Feature | Description |
|---|---|
| 🧠 Dream Mapper | AI builds your Student DNA profile and matches top universities with live admit probability |
| 📅 Journey Copilot | 12-month personalised action plan with streak tracking |
| ✍️ SOP Studio | AI generates + "roasts" your Statement of Purpose |
| 💰 Smart Loan Bridge | Upload admit letter → Poonawalla Fincorp loan offer in 60 seconds |
| 🏆 Scholarship Finder | AI-powered scholarship matching based on your profile |
| ✈️ Visa Checklist | Country-specific visa guides with interactive checklists |
| 📁 Document Organizer | AI-powered document management with insights |
| 💸 Budget Calculator | Advanced financial planning with visual breakdowns |
| 🎤 Interview Prep | University-specific interview preparation with question banks |

## 🔧 Tech Stack
- **Frontend**: React + Vite + Tailwind CSS + Framer Motion
- **Backend**: Node.js + Express
- **AI**: OpenAI GPT-4o-mini
- **State**: React Context API

## 📁 Demo Mode
Works fully without an API key using intelligent mock data.
Add `OPENAI_API_KEY` to `backend/.env` to enable real AI responses.
